# The Decor House: interior design and architecture portfolio
React 18, TypeScript, Vite, Tailwind v3, Framer Motion, GSAP ScrollTrigger, Lenis.

## Run
    npm install
    npm run dev

## Build and deploy
    npm run build   # output in dist/. Deploy to Vercel or Netlify with an SPA rewrite to index.html

## Customize
- Studio name and copy: src/pages/*, src/components/Footer.tsx
- Projects and images: src/data/projects.ts (Unsplash placeholders)
- Colors and fonts: tailwind.config.ts
